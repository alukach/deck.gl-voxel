# MapLibre example

The example draws a WebGPU `VoxelLayer` over a MapLibre basemap. Use the timeline to step through the data or press Play. Run the example with `pnpm dev:maplibre`.

## Datasets

- Hurricane Helene shows hourly ERA5 cloud cover. [GeoZarr store](https://helene-voxel-329134478190-eu-central-1.s3.eu-central-1.amazonaws.com/era5-helene.zarr/fraction_of_cloud_cover/zarr.json)
